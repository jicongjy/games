# 차려내라! 한 상: 기획서 v0.1

2인 실시간 웹 카드게임. 원작의 규칙 구조를 유지하고, 이름, 테마, 그림, 문구는 전부 새로 만든다.

## 1. 확정 사항

- 게임 이름: **차려내라! 한 상**
- 승부: **1판 승부** (끝나면 "한 판 더")
- 플레이어: 이름만 입력 (고정 캐릭터 없음)
- 톤: 밝고 단순한 색면 + 도형 + 굵은 고딕 (심볼릭 카드 스타일)
- 설정: 마감 전, 두 요리사가 같은 시장 재료로 5개 코스를 차려내는 심야 대결. 익명의 심사위원이 코스에 별을 남기고 간다.

## 2. 코스 5개

| 코스 | 색 | 아이콘 | 색상값(안) |
|---|---|---|---|
| 밑반찬 | 연두 | 잎 | #A5CF4A |
| 국·탕 | 주황 | 뚝배기 | #F28C28 |
| 생선구이 | 파랑 | 물고기 | #2F5FD0 |
| 불고기 | 빨강 | 불꽃 | #E0402F |
| 후식 | 분홍 | 약과 | #F2A7C0 |

색약 대비를 위해 색과 아이콘을 항상 같이 쓴다.

## 3. 규칙 요약 (구현 기준)

- 덱 60장 = 코스 5개 × (단골 예약 3장 + 조리 카드 단계 2~10 각 1장)
- 시작 시 각자 패 8장, 식재료 창고(덱) 44장
- 내 차례에 **내기 → 가져오기** 순서로 한다.
  - 내기: 내 코스 줄에 올리거나, 해당 색 시장 좌판에 내려놓는다.
  - 가져오기: 창고 맨 위 카드, 또는 좌판 5곳 중 한 곳의 맨 위 카드. 방금 내려놓은 카드를 같은 차례에 도로 가져올 수 없다.
- 코스 줄 규칙
  - 단계 숫자는 오름차순으로만 올린다 (낮은 숫자를 뒤에 낼 수 없다).
  - 단골 예약 카드는 그 코스에 조리 카드를 내기 전에만 낼 수 있다.
- 종료: **창고의 마지막 카드를 뽑는 순간 즉시 끝난다.** 화면에 "마감까지 N장"을 항상 크게 보여 준다. 10장 이하면 색과 효과음이 바뀐다.
- 점수 (코스마다 계산해서 더함)
  - 시작한 코스만 계산한다. 시작하지 않은 코스는 0점.
  - (조리 카드 숫자 합 − 20) × (1 + 예약 카드 수)
  - 예약 카드 포함 8장 이상이면 별 한 개: +20점 (배수 계산 후에 더한다)

## 4. 용어

| 원작 규칙 | 게임 안 이름 |
|---|---|
| 원정 줄 | 코스 줄 |
| 숫자 카드 | 조리 카드 |
| 투자 카드 | 단골 예약 |
| 합계 −20 | 기본 재료비 |
| 8장 이상 보너스 | 별 한 개 |
| 중앙 버림 더미 | 시장 좌판 (코스별 5곳) |
| 덱 | 식재료 창고 |

"미슐랭"이라는 이름, 로고, 가이드북 이미지는 상표 위험이 있어 쓰지 않는다. 별 개념만 쓴다.

## 6. 단골 예약 카드 문구 (코스별 3장, 총 15장)

- 밑반찬: "나물 한 접시, 오늘 책임져 주세요"
- 국·탕: "뜨끈한 국물, 오늘 책임져 주세요"
- 생선구이: "노릇한 생선 한 마리, 오늘 책임져 주세요"
- 불고기: "달큰한 불고기, 오늘 책임져 주세요"
- 후식: "달콤한 마무리, 오늘 책임져 주세요"

## 7. 화면 워딩

- 내 차례: "코스에 올리거나, 좌판에 내려놓으세요"
- 가져오기: "창고에서 한 장, 혹은 좌판에서 한 장"
- 남은 장수: "마감까지 44장" → 10장 이하 "곧 마감입니다"
- 별을 받을 때: "익명의 심사위원이 별 한 개를 남기고 갔습니다"
- 감점 코스 안내: "시작만 하고 마무리 못 한 코스가 있습니다"
- 결과 심사평
  - 크게 이김: "오늘 밤 심사위원은 이 주방의 이름을 기억할 겁니다."
  - 근소하게 이김: "한 접시 차이로 별이 갈렸습니다."
  - 근소하게 짐: "아쉽지만 다음 상차림이 기대됩니다."
  - 크게 짐: "재료만 늘어놓다 마감 종이 울렸네요. 다음 영업을 노려 보세요."

## 8. 화면 흐름

1. 시작: 이름 입력 → "주방 열기"(방 만들기) / "주방 들어가기"(방 코드)
2. 대기: 방 코드 공유, 상대 입장 시 시작
3. 대결: 상단 상대 코스 줄, 중앙 좌판 5곳 + 창고(남은 장수), 하단 내 코스 줄 + 패 8장
4. 결과: 코스별 점수표(기본 재료비, 예약 배수, 별 보너스), 심사평, "한 판 더"
