# 집중하는 동안 돌아가는 작은 회사

상태: 보류 (2026-11-22). 이유: 켜 둔 시간이 일한 시간은 아니고, 시간 트래킹을 넣으면 생산성 앱이 되어 범위가 커진다.
출처: jicong-ai-os `domains/game-dev/references/concepts-v2-work.md`의 D안.

- 한 줄: 브라우저 탭에 집중 타이머를 켜 두면 그동안 내 작은 회사 직원들이 일하고, 타이머가 끝나면 성과 상자를 연다.
- 섞은 것: 방치(집중 시간 = 생산 시간) + 운(성과 상자) + 경영(직원 채용·사무실 확장).
- 반복: 25분 집중 → 상자 열기(운) → 직원·책상·장비에 투자 → 다음 집중이 더 큰 성과.
- 웹에 맞는 이유: 탭을 켜 두는 것 자체가 놀이 방식이라 웹 제약이 오히려 장점이 된다. 진행은 시작 시각과 끝난 시각 차이로 계산한다.
- 장점: 매일 직접 쓰며 시험할 수 있다. "내가 매일 쓰려고 만든 게임"이라는 포트폴리오 이야기가 생긴다.
- 위험: 집중했는지 확인할 수 없다(자기 신고). Forest 같은 집중 앱이 이미 있어서, 차별점은 "회사가 커지는 경영"에 둔다.
