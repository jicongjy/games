# 레퍼런스: WINTER_IS_COMING

https://github.com/yike-shi/WINTER_IS_COMING (2026-11-23 사용자가 재미있다고 준 레퍼런스. README 기준으로 정리)

- 무엇: Mac 바탕화면에 눈이 내려 창 위, Dock, 화면 바닥에 쌓인다. 마우스를 옆으로 움직이면 눈덩이가 굴러 커지고, 셋을 쌓으면 눈사람이 된다. 창을 빠르게 끌면 눈이 날아간다.
- 만든 방식: Swift 파일 하나, 그림은 전부 코드로 그림. 인터넷 연결 없음. Windows 판은 베타.
- 형식: 리서치의 "곁들이는 게임(데스크톱 동반자)". 일하는 화면 위에 얹혀 있고, 일하다 손이 쉴 때 만지작거린다.
- 가져올 것: 일하는 화면 옆에 늘 있는 느낌, 클릭 없이 마우스만 움직여도 반응하는 손맛, 작은 것이 쌓이는 모습이 그대로 보이는 것.
- 가져오지 않을 것: 눈, 눈덩이, 눈사람 같은 소재와 그림.
- 웹과의 차이: 바탕화면과 다른 창 위에 그리려면 Mac 앱이어야 한다. 웹 브라우저는 자기 탭 안에서만 그릴 수 있다.
